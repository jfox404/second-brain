# User Model

Durable facts about the user. Updated by the reflect skill after corrections and discoveries.

## Preferences

Communication style, formatting conventions, tool preferences — anything that applies across sessions.

## Domain Context

Domain-specific knowledge about the user's world that an agent should know: role, tools they use, systems they work with, terminology they prefer.

## Corrections

Every user correction the agent has received. Each entry should include the correction, the context (what operation was running), and the date. Agents should check this section before starting a familiar operation to avoid repeating mistakes.

## Routines

Recurring workflows the user follows that aren't captured by individual skills. Patterns like "always do X after Y" or "every Monday morning, do Z."

## Usage

- **Read** this file at the start of any session to understand the user.
- **Write** to this file via the reflect skill after corrections or durable discoveries.
- Each section uses a flat list of entries. Newest entries at the bottom.
